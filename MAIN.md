# CampusTrack 📚

**A Student Assignment & Task Management Application**

CampusTrack is a desktop-based application built using Python and CustomTkinter to help students organise their academic assignments and track their progress.

## ✨ Features

- Add and manage assignments
- Organise tasks by subject and due date
- Track pending and completed assignments
- Search through assignments
- View dashboard statistics
- Save tasks locally using JSON
- Modern dark-themed graphical interface

## 🛠️ Technologies Used

- Python
- CustomTkinter
- JSON

## 🚀 How to Run

1. Install Python.
2. Install CustomTkinter:

   `pip install customtkinter`

3. Run the application:

   `python collegetrackerprj.py`

## 🎯 Purpose

This project was created to explore Python GUI development and build a practical tool for student productivity.
